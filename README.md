# Менеджер автомобилей и запчастей

Это полнофункциональный веб-приложение для управления автомобилями и запчастями. Проект состоит из backend на .NET ASP.NET Core с API и базой данных SQLite, а также frontend на React с Vite.

## Функциональность

- **Управление автомобилями**: Добавление, редактирование, удаление автомобилей (марка, модель, год).
- **Управление запчастями**: Добавление, редактирование, удаление запчастей (название, категория, цена).
- **Вкладки интерфейса**: Переключение между разделами автомобилей и запчастей.
- **API интеграция**: Полный CRUD через REST API.
- **Современный UI**: Белый фон, синие кнопки, иконки, адаптивный дизайн.

## Технологии

- **Backend**: .NET 10, ASP.NET Core, Entity Framework Core, SQLite.
- **Frontend**: React 18, Vite, CSS.
- **База данных**: SQLite (автоматически создается при запуске).

## Как запустить проект

### Предварительные требования

- **.NET SDK 10** (скачать с https://dotnet.microsoft.com/download)
- **Node.js 18+** (скачать с https://nodejs.org/)
- **Git** (скачать с https://git-scm.com/)

### Шаг 1: Запуск Backend (API)

1. Откройте терминал и перейдите в папку backend:
   ```
   cd backend
   ```

2. Восстановите зависимости .NET:
   ```
   dotnet restore
   ```

3. Запустите API сервер:
   ```
   dotnet run
   ```

   API будет доступно по адресу: `http://localhost:5132`

   При первом запуске автоматически создастся база данных SQLite с таблицами для автомобилей и запчастей.

### Шаг 2: Запуск Frontend (React)

1. Откройте новый терминал и перейдите в папку first-app:
   ```
   cd first-app
   ```

2. Установите зависимости Node.js:
   ```
   npm install
   ```

3. Запустите React приложение в режиме разработки:
   ```
   npm run dev
   ```

   Frontend будет доступно по адресу: `http://localhost:5173`

### Порядок запуска

**Важно**: Сначала запустите backend (API), затем frontend. Это обеспечит корректную работу интеграции между приложениями.

## Использование

1. Откройте браузер и перейдите на `http://localhost:5173`.
2. Используйте вкладки "🚗 Автомобили" и "🔧 Запчасти" для переключения между разделами.
3. Добавляйте, редактируйте или удаляйте записи с помощью форм и кнопок в таблицах.
4. Все изменения автоматически сохраняются в базе данных через API.

## API Endpoints

### Автомобили
- `GET /api/cars` - Получить все автомобили
- `GET /api/cars/{id}` - Получить автомобиль по ID
- `POST /api/cars` - Добавить новый автомобиль
- `PUT /api/cars/{id}` - Обновить автомобиль
- `DELETE /api/cars/{id}` - Удалить автомобиль

### Запчасти
- `GET /api/parts` - Получить все запчасти
- `GET /api/parts/{id}` - Получить запчасть по ID
- `POST /api/parts` - Добавить новую запчасть
- `PUT /api/parts/{id}` - Обновить запчасть
- `DELETE /api/parts/{id}` - Удалить запчасть

## CORS Настройка

Backend настроен для разрешения запросов от frontend (localhost:5173). Код в `Program.cs`:

```csharp
builder.Services.AddCors(options =>
{
    options.AddPolicy("AllowSpecificOrigin", builder =>
    {
        builder.WithOrigins("http://localhost:5173")
               .AllowAnyMethod()
               .AllowAnyHeader();
    });
});

app.UseCors("AllowSpecificOrigin");
```
